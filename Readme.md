# Portfolio Homepage

A responsive "About Me" homepage built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. It introduces me, showcases six of my projects, and gives visitors a way to get in touch.

**Live site:** [View it here](https://macnum.github.io/YOUR-REPO-NAME/)

## Preview

![Screenshot of the portfolio homepage](./images/preview.png)

## Features

- Hero section with a portrait, short bio, and social links
- "My Work" grid with six project cards, each linking to its source code and live demo
- Contact footer with email and social links
- Fully responsive layout for desktop, tablet, and phone
- Slanted background section created with a CSS `linear-gradient`
- Responsive images using `srcset` and `sizes`
- Accessible markup: semantic HTML, descriptive alt text, and a single `h1`

## Built With

- HTML5
- CSS3 (custom properties, Flexbox, Grid, floats, media queries)
- [Google Fonts](https://fonts.google.com/) (Playfair Display)
- [Devicon](https://devicon.dev/)

## What I Practised

- Building a layout with Flexbox and Grid
- Using media queries to adapt the design at 768px and 480px
- Making a photo sit half inside and half outside a box, with text wrapping around it using `float`
- Finding and fixing horizontal overflow on small screens
- Writing meaningful alt text and semantic HTML
